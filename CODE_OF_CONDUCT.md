# Code of Conduct

## Our standard

Everyone participating in the Vyshka project (issues, pull requests, discussions, and any
other project space) is expected to:

- Be respectful. Disagree with ideas, not with people.
- Assume good faith, especially across language barriers; this is a game-server community
  project with contributors from many backgrounds.
- Keep criticism technical and specific. "This breaks re-delivery dedup because..." helps;
  ridicule does not.
- Respect maintainers' decisions once a discussion has run its course, even when the
  outcome is not your preference.

Unacceptable behavior includes harassment, personal attacks, discriminatory remarks,
sustained disruption, and publishing others' private information.

## Enforcement

Violations can be reported to the maintainer at <americanemt@gmail.com>. Reports are
handled confidentially. Consequences scale with severity and repetition: a warning,
temporary exclusion from project spaces, or a permanent ban.

## Scope

This applies in all project spaces and when representing the project publicly.
